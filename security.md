# security

## report a vulnerability

Email [security@tnl.dev](mailto:security@tnl.dev) to report a
suspected security vulnerability in tnl.

Please do not report vulnerabilities through public GitHub issues,
discussions, or pull requests.

Include what you can:

- The affected component and version or commit.
- Steps to reproduce the issue, ideally with a minimal proof of concept.
- The potential impact and any access or configuration required.
- Relevant logs or configuration, with secrets and personal data removed.

You do not need a complete report to contact us.

## coordinated disclosure

Please keep vulnerability details private while we investigate and
prepare a fix. We'll coordinate public disclosure with you.

## security model

See the [security documentation](https://tnl.dev/docs/security) for
encryption boundaries, access controls, and trust assumptions, and the
[self-hosting guide](https://tnl.dev/docs/self-hosting) for operating
your own tnl server.
