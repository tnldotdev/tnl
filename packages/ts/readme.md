# `@tnldotdev/tnl`

Use tnl to give your app a public URL or connect it to a private service. The package includes the `tnl` CLI and integrations for Vite and Next.js.

```sh
npm install -D @tnldotdev/tnl
npx tnl init
npm run dev
```

`tnl init` sets up your project. Start your app normally. It still runs on localhost if you have not signed in or control is offline. To get a public URL, run `npx tnl auth login` and restart the app.

See the [quickstart](https://tnl.dev/docs), [framework guides](https://tnl.dev/docs/frameworks), and [main README](https://github.com/tnldotdev/tnl#readme).
